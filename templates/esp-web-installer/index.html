Hardware and firmware

Use a desktop browser with Web Serial support, such as Chrome or Edge. Open the HTTPS installer directly in its own browser tab.

Back up existing settings first. Factory installation can erase firmware, Wi-Fi credentials and other device data. This does not remotely update a running device. The browser only accesses the serial port you choose.

If the board does not connect

  • Use desktop Chrome or Edge with Web Serial enabled. Safari, mobile browsers and embedded views may not support installation.
  • Try a known data cable and a direct USB port. Close ESPHome, Arduino and serial consoles that already hold the port.
  • If no port appears, follow the board manufacturer's USB driver instructions; Linux may require serial-port group permissions.
  • For boards that need download mode, hold BOOT while connecting USB or tapping RESET, then release BOOT after connection. Follow the exact board guide.
  • A chip match does not confirm the board's pins, flash size or attached hardware. Do not install a profile for another model.
  • After flashing, reset or reconnect the board if needed. Follow the selected profile's setup guide for networking and application configuration.
